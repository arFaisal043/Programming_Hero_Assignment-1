# Title: Advantage of The Four Pillars of OOP

## Introduction: 
- OOP stand for Object Oriented Programming. It is one of the most important fundamental topic in Computer Science. and also for Interview perspective. This is the way of write code into structure way by class, object etc.

## Pillars of OOP:
- There are 4 pillars in OOP.
1. Inheritance 
2. Polymorphism
3. Abstraction and 
4. Encapsulation

## 1. Inheritance:
- This is based on parent child relationships. You can create a parent and then child, if that you extend with parent then you can use all properties of parent.
- Benefit: Less duplication.

## 2. Encapsulation:
Bundling properties and methods together while restricting direct access to internal states.
- It has some access modifier such as public, private, protected.

## 3. Polymorphism:
- You can use same method name on different object.

## 4. Abstraction:
- Hiding complex implementation details and showing only the necessary features.

## Conclusion:
- OOP solve big problems into small module. This is an programming structure to write code. TypeScript helps to so many complex problem to easy way by OOP. That's why in big TypeScript project like NestJS rely on OOP.
